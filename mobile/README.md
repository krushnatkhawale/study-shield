# Interrupter - Mobile App

This is the controller application for the Interrupter system. It allows you to remotely lock an Android TV device on the same network.

## Features
* Send custom lock messages to the TV.
* Simple IP-based connection.

## Installation
1. Open the project in Android Studio.
2. Select the `mobile` configuration.
3. Connect your Android mobile device via USB or WiFi.
4. Click **Run** to install the app.

## How to Use
1. Ensure your mobile device is on the same WiFi network as the Android TV.
2. Open the app on your phone.
3. Enter the **IP Address** of the TV (e.g., `192.168.1.15`). You can find this in the TV's Network Settings.
4. Enter the **Message** you want to display on the TV (e.g., "Dinner is ready!").
5. Tap **Lock TV**.

## Requirements
* Android 6.0 (API 23) or higher.
* Both devices must be on the same local network.
